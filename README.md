# dsh-music-player

悬浮在 DeepSeek Harness Web 界面上的黑胶音乐播放器，带 B 站音源引擎。

一个 DSH UI 插件：右下角一枚毛玻璃圆圈，中间黑胶唱片旋转；点开变成控制长条，齿轮打开完整面板（歌单、搜索、进度、音量、播放模式）。

> 非官方项目。与哔哩哔哩（Bilibili）、DeepSeek 均无关联，未经其认可或赞助。

## 功能

**播放器**

- 悬浮黑胶：可拖动，位置自动钳制在屏幕内并记忆；点击展开为 3× 宽的控制长条，黑胶向上淡出
- 上一首 / 播放暂停 / 下一首；底部细线可拖动跳转
- 面板内：可拖动的进度条、局部音量（含静音）、独立于系统的音量记忆
- 播放模式：单曲循环（涟漪 + 图标脉动）、随机播放（流光 + 图标脉动），均踩 1/4 拍；选择持久化
- 所有按钮同一套毛玻璃配方：55% 中性灰 + 9px 模糊 + 象牙白图标

**B 站音源**

- 读取**公开的收藏夹（歌单）**：粘贴 `https://www.bilibili.com/medialist/detail/ml...` 链接即可载入
- 面板内置搜索框：输入歌名直接搜 B 站视频，点结果立即播放（临时顶替歌单，播完自动回到歌单）
- 整轨道缓冲成 Blob 后播放，因此进度条可以精确拖动（边下边播的流在 Chromium 里会拒绝按时间跳转）
- 宿主侧代理音频流（`Range` 透传），无需关心 CDN 的 Referer/CORS 限制
- 打开面板、每次切歌、每次播完都会静默刷新歌单（3 秒节流）

**界面**

- 全部渲染在 DSH 的 `shell.overlay` 悬浮层，不遮挡下层交互
- 亮/暗主题跟随宿主 token；`prefers-reduced-motion` 下自动停用动画

## 安装

插件是一个标准的 DSH bundle（`package.json` 里声明 `dsh.bundle.patch` 与 `dsh.client`）。

```bash
# 本地目录安装
dsh plugin --profile <profile> add link:<本仓库的绝对路径>

# 或者把目录放进 profile 后，用插件管理器 / 设置页安装
```

安装后在「设置 → 插件」里可以看到 **黑胶音乐播放器**，启用即可出现在界面右下角。

## 使用

1. 点击右下角圆圈展开，点下方齿轮打开面板
2. 面板里的 **?** 按钮有完整指引：如何在 B 站拿到可用的歌单链接
3. 粘贴链接 → 点「载入」→ 点歌名播放
4. 齿轮两侧的模式圆点：左＝单曲循环，右＝随机播放

## 数据存储

播放器的设置（歌单链接、播放模式、音量、悬浮位置）保存在插件包内的 `data/settings.json`，**不依赖浏览器 localStorage**，因此换端口、重装插件、重启应用都不会丢。

播放历史、登录凭证等**不做任何存储**——本项目不含登录功能。

## 隐私与网络

- 只向 `api.bilibili.com`、`passport.bilibili.com`（仅取访客指纹）、B 站音频 CDN 发起请求
- **不采集、不上传任何用户数据**，无遥测、无统计
- 音频仅在内存中缓冲用于播放，**不提供下载或导出功能**
